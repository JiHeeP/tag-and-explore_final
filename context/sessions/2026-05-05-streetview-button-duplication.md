## 이미지 권장 크기 산정 근거

- 편집 화면의 스테이지는 CSS 기준 최대 `1100px` 폭이다.
- 보기 화면은 CSS 기준 최대 약 `1480px` 폭까지 커진다.
- 고해상도 화면에서 선명하게 보이려면 실제 이미지 픽셀은 표시 폭의 약 2배가 좋다.
- 따라서 보기 화면 최대 폭 `1480px * 2 = 2960px`를 기준으로, 16:9 이미지는 약 `2960x1665`가 최적 기준선이다.
- 실무적으로 외우기 쉬운 권장값은 `2560x1440` 이상, 더 선명한 값은 `3000x1688`, 상한 추천은 `3840x2160`이다.
